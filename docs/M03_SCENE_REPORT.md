## Адаптивность
Виджет-тесты: 1024×640, 1366×768, 1920×1080, 2560×1440, 3840×2160 — без переполнений, весь дом в кадре после загрузки, выбор работает; HiDPI учитывается при выборе разрешения текстуры.

## Визуальная проверка (скриншоты `docs/screenshots/m03/`)
Реальное окно приложения против запущенного Core (изолированная БД), сняты: демо до сохранения, общий вид, все 5 комнат, наведение, выбранное устройство, карточка Registry, контекстное меню, архивная привязка, мин./макс. масштаб, легенда, офлайн-копия.

Найдено и исправлено по скриншотам: панель индикаторов висела над низкой перегородкой; лица ботов торчали вбок; не было названий комнат; подпись «Кабинет» попадала в соседнюю комнату; полосы под домом (BlendMode.softLight на GPU); офлайн возможности показывались кодами; «Подробнее» был активен без Core; ассет сцены не попадал в сборку (pubspec).
