# Питание: руководство пользователя

**Что это**: включить компьютер по сети, выключить, перезагрузить, усыпить и перезагрузить dual-boot ПК в другую ОС (один раз) — из AER HOME, с подтверждением и журналом.

## Карточка компьютера («Питание»)
- **Состояние**: «Включён», «Не отвечает» (выключен, спит, загружает другую ОС без агента или нет сети — AER не гадает), «Включается», «Выключается», «Перезагружается», «Переключает ОС», «Неизвестно».
- **Сейчас**: какая ОС загружена; **последний контакт**; работает ли агент или он в **режиме проверки** (тогда команды не выполняются, результат — SIMULATED).
- Кнопки: **Включить, Выключить, Перезагрузить, Сон, Сменить ОС**. Недоступная кнопка серая; наведите — увидите причину (нет агента, запрещено политикой, нет загрузочной записи, BitLocker, Core на этом же ПК…).
- **Проверить состояние** — обновить данные Мониторинга и агента, без подтверждения.
- **Wake-on-LAN…**, **Политика**, **История**, **Удалённый доступ**.

## Как выполняется команда
1. Нажмите действие → AER запросит у Core **план**: проверки (агент, запись загрузки, Secure Boot, BitLocker) и риски.
2. Для выключения, перезагрузки, сна и смены ОС нужно отметить «Я сохранил работу…» — без этого кнопка неактивна.
3. Подтверждение одноразовое и действует 2 минуты.
4. Под карточкой появится ход выполнения: «В очереди — ждёт агента» (здесь можно **Отменить**), «Передано агенту», «Выполняется — ждём результат», затем итог.
5. Итоги: «Выполнено»; «Ошибка» (с причиной); «Нет подтверждения — состояние неизвестно» (AER не выдаёт это за успех); «Отменено»; «SIMULATED — ничего не выполнено».
6. AER **никогда не повторяет** выключение или перезагрузку сам.

## Сменить ОС
Выберите ОС (текущая не предлагается) → план → подтверждение. Используется одноразовая загрузка UEFI: постоянный порядок загрузки, GRUB и rEFInd не меняются; если цель не загрузится, следующая обычная загрузка пойдёт как раньше. Успех — когда в целевой ОС ответил агент AER; если загрузилась прежняя ОС — «Ошибка: загрузилась другая ОС». По умолчанию смена ОС выключена в политике.

## Включить по сети
Нужны: настроенный MAC, разрешённая отправка в Core и Core на **другом** постоянно включённом компьютере. Если Core на этом же ПК — кнопка недоступна, и это объяснено в карточке.

## В доме
Нажмите на привязанный компьютер: в быстрой карточке — блок «Питание» с состоянием, ходом команды и только **доступными** сейчас действиями, «Управление питанием», «Удалённый доступ».

## Без связи с Core
Данные помечаются как устаревшие, команды недоступны. Агент на компьютере без Core ничего не выполняет.
