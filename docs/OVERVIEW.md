# AER HOME — пакет проектной документации для Claude Code

**Версия:** 0.1 planning baseline • **Дата:** 2026-10-26 • **Статус:** спецификация, не готовый продукт.

AER HOME — персональная, локальная система контроля цифрового дома. Интерфейс — уютный бежевый изометрический дом с редактируемыми комнатами, устройствами, ботами и доступом к техническим функциям. Альтернативный классический интерфейс — полнофункциональный, без игровой сцены.

## Начните отсюда

1. `CLAUDE.md` (в корне) — обязательные правила для Claude Code.
2. `docs/PRODUCT.md` — цель, пользовательские сценарии, границы проекта.
3. `docs/ARCHITECTURE.md` — приложение, Core, агенты, контракты, развёртывание.
4. `docs/MODULES.md` — владельцы модулей и их интерфейсы.
5. `docs/UX_DESIGN.md`, `docs/SCENE_EDITOR.md`, `docs/DESIGN_TOKENS.md` — интерфейс и редактор.
6. `docs/REMOTE.md`, `docs/POWER_DUALBOOT.md` — удалёнка, файлы, буфер, WoL, две ОС.
7. `docs/MONITORING_BOTS.md`, `docs/SECURITY.md` — мониторинг, боты и безопасность.
8. `docs/INTEGRATIONS.md` — результаты оценки внешних проектов и лицензий.
9. `docs/ROADMAP.md`, `docs/ACCEPTANCE.md` — порядок работ, критерии приёмки.
10. `contracts/openapi.yaml`, `contracts/events.schema.json`, `examples/home.scene.json` — стартовые примеры контрактов; проекты контрактов, могут меняться только через версионированное решение.

**Важно:** Не начинать проект с написания полноценного стримингового движка, сложных серверных стеков мониторинга или нативных мобильных приложений. Сначала валидировать архитектуру, затем делать тонкие вертикальные срезы.

## Принятые требования

- Только для личного пользования. **Не SaaS**, нет подписок, multi-tenancy, биллинга.
- Flutter/Dart для нативных настольных клиентов Windows и Ubuntu.
- Swift/SwiftUI для iPhone; Kotlin/Jetpack Compose для потенциального Android.
- На мобильном клиенте первоначальный выбор: «Изометрический дом» / «Обычный интерфейс»; можно переключить позже.
- Компьютер вне дома: полный рабочий стол, мышь, клавиатура, двусторонний текстовый буфер, передача файлов, при технической возможности drag-and-drop.
- Телефон вне дома: **только разрешённые запущенные приложения**, отдельные окна или безопасные API-панели, без доступа ко всему рабочему столу; когда недоступно — честный отказ, не скрытый fallback на desktop.
- Wake-on-LAN, удалённое переключение Ubuntu ↔ Windows (одна активная ОС), управление питанием, мониторинг серверов, ботов, сети, Android TV, ошибки и журналы.
- Добавление устройств/ботов/сервисов через короткий мастер без редактирования кода.
- Сейчас отдельного сервера нет: Core временно работает на основном Ubuntu ПК. Позже — отдельный маломощный Linux сервер (рассчитывать на 4 ГБ RAM, неизвестный CPU/HDD).
- Jellyfin, собственный NAS и фотохранилище **не входят в обязательный MVP**. Медиа — браузер на ПК через Sunshine + Moonlight, фото — внешний сервис по желанию.
- Основная графика рендерится на клиентах, не на сервере.
