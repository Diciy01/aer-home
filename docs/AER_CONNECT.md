# AER Connect (Windows x64)

Самостоятельный клиент удалённого доступа семейства AER. Сцена, Registry,
Monitoring, Bots и Power в приложение не входят. Используются общий движок
`aer_remote`, FreeRDP viewer и неизменённые токены/тема AER HOME из `aer_widgets`.

## Подключение

1. В AER HOME создайте клиента в «Удалённый доступ → Клиенты», выберите
   компьютеры и права, получите одноразовый код и отпечаток Gateway.
2. В AER Connect введите IP, DDNS или домен собственного Gateway.
3. Нажмите «Проверить сертификат», сверьте SHA-256 по независимому каналу с
   AER HOME. Только после сверки подтвердите pin и введите код сопряжения.
4. Выберите разрешённый компьютер. Хост может требовать локального согласия.
5. Просмотр, переподключение и завершение находятся внутри приложения.
   Файлы передаются только в папку обмена, с лимитом хоста и SHA-256.

Учётная запись клиента `aerc1` и профиль с pin хранятся вместе через
`flutter_secure_storage`: DPAPI текущего пользователя, отдельные ProductName
`AER Connect` и ключ `aer-connect.remote.profile.v1`. Токен владельца Core
никогда не запрашивается. «Удалить сервер» завершает сеанс и удаляет локальный
профиль; для полного отзыва клиента используйте AER HOME.

Изменение сертификата требует нового сопряжения после независимой сверки.
Доверие системному CA не заменяет закрепление. Gateway не проксирует owner API.

## Сборка и упаковка

Те же SDK/FreeRDP, что в `WINDOWS.md`; конечному пользователю они не нужны.

```powershell
$env:AER_FREERDP_PREFIX = $prefix
cd apps/connect
flutter pub get
flutter analyze
flutter test
flutter build windows --release
cd ../..
./tools/windows/package-connect.ps1 -OutputDir C:/temp/aer-connect-package -FreeRdpPrefix $prefix
```

ZIP содержит `app/`, app-local FreeRDP/OpenSSL/CRT, notices и лицензии,
`install.ps1` и `uninstall.ps1`. После распаковки выполните `install.ps1`:
установка в `%LOCALAPPDATA%/Programs/AER Connect` с ярлыком текущего пользователя.
`-InstallDir` позволяет выбрать новый каталог; существующие файлы и ярлыки не
перезаписываются. Удаление из каталога установки сверяет SHA-256 и сохраняет
добавленные/изменённые файлы и защищённые учётные данные ОС. Удалить профиль
можно в приложении. Службы, автозапуск, firewall, системный RDP не меняются.

Крестик окна завершает сеанс и закрывает нативные ресурсы; ограниченный тайм-аут
закрывает приложение при зависшем сетевом запросе. При аварии/потере сети
Gateway и агент применяют сроки сеанса и правила переподключения.

## Ограничения приёмки

Результаты и артефакты — `M14_4_REPORT.md`. Синтетический Windows Host проверяет
настоящие RDP/TLS/Gateway и права, но не подтверждает реальный захват/SendInput.
Интернет и чистая Windows VM требуют отдельной проверки. Подпись пакета и
политики SmartScreen/PowerShell пользователя не заменяются установщиком.
