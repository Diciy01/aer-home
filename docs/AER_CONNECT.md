# AER Connect (Windows x64)

Одно приложение удалённого доступа семейства AER: **этот компьютер** принимает
подключения по своему ID и паролю, и **с него** можно подключиться к другому
компьютеру по его ID и паролю. Всё идёт через собственный домашний AER Gateway
(ADR-017, ADR-018): без VPN, проброса портов на клиентах, RustDesk/Tailscale и
чужих серверов. Используются общий движок `aer_remote`, FreeRDP viewer, нативный
Windows Host (`aer-shadow`) и неизменённые токены/тема AER HOME из `aer_widgets`.

## Установка

1. Распакуйте `aer-connect-anywhere-*.zip`.
2. В PowerShell **обычного пользователя** (не «от имени администратора»):
   `./install.ps1` — установка в `%LOCALAPPDATA%\Programs\AER Connect` и ярлык в
   меню «Пуск». `-InstallDir` — другой новый каталог, `-NoShortcut` — без ярлыка.
3. Запустите AER Connect из меню «Пуск». SDK, Visual Studio, vcpkg, FreeRDP,
   Go и Flutter не нужны: всё app-local.

Обновление: `./install.ps1 -Upgrade` (тот же `-InstallDir`). Заменяются только
неизменённые файлы прежней установки; при добавленных/изменённых файлах
обновление останавливается, ничего не заменив. Регистрация устройства (ID,
учётки) хранится в профиле пользователя и **переживает переустановку**.
Удаление: `uninstall.ps1` из каталога установки — удаляет неизменённые файлы,
свой ярлык и свою запись автозапуска; регистрацию не трогает (её удаляют в
приложении: «Удалить регистрацию»).

## Первый запуск: регистрация компьютера

Один раз на каждом компьютере:

1. **Адрес сервера** — IP, имя DNS/DDNS или `адрес:порт` домашнего Gateway.
2. **Проверить сертификат** → сверьте показанный SHA-256 с тем, что владелец
   сервера получил командой `aer-admin fingerprint`, и отметьте «Отпечаток
   совпадает». Если пакет собран с `connect.json`, сверка автоматическая и
   несовпадение запрещает подключение.
3. **Имя компьютера** и **код регистрации** от владельца (`aer-admin enroll-code`).
4. «Зарегистрировать» — компьютер получает постоянный 9-значный **ID**.

Ручное редактирование JSON не требуется. Старый «код сопряжения клиента» тоже
принимается (ссылка «У меня код сопряжения клиента») — прежний режим со
списком разрешённых владельцем компьютеров.

## Каждый день

**Этот компьютер**: ID, временный пароль, статус связи с сервером (В сети /
Подключение / Переподключение / Не в сети / Отозвано), переключатель входящих
подключений, постоянный пароль, права, индикатор и кнопка **«Остановить»**
активного удалённого управления.

**Подключиться**: введите ID и пароль другого компьютера → «Подключиться».
На том компьютере появится окно подтверждения — сеанс начнётся только после
«Да». Рабочий стол открывается внутри AER Connect; «Завершить» — конец сеанса,
«Переподключиться» — новое соединение в том же сеансе. Сообщения: неверный
пароль, компьютер не найден, не в сети, занят, входящие выключены, слишком
много попыток. Отклонённый пароль стирается из поля и не отправляется повторно.

## Пароли и безопасность

- **Временный пароль** (8 символов) создаётся при каждом запуске, меняется после
  каждого сеанса, по кнопке, после «Остановить» и после серии неверных попыток.
  Нигде не хранится.
- **Постоянный пароль** выключен по умолчанию. «Включить» — свой пароль не короче
  10 символов (≥6 разных); на компьютере остаётся только PBKDF2-хэш
  (600 000 итераций). Изменить/выключить — там же.
- Пароль проверяет **сам компьютер-хост**: он запечатывается на его ключ
  X25519 для одной попытки, сервер видит только шифротекст.
- Каждое входящее подключение подтверждается на экране хоста, во время сеанса
  видно окно со «Стоп». Блокировка Windows, UAC/защищённый рабочий стол и потеря
  захвата завершают доступ. Неприсмотренного доступа без подтверждения нет.
- Входящие подключения работают, пока AER Connect открыт. «Запускать AER Connect
  при входе в Windows» — явная настройка пользователя (HKCU\…\Run), по умолчанию
  выключена. Службы, драйверы, firewall, UAC и системный RDP не меняются.
- Запуск AER Connect от имени администратора выключает входящие подключения
  (Host отказывается работать с повышенными правами); исходящие работают.
- Учётки устройства, ключ X25519, верификатор постоянного пароля и pin хранятся
  через `flutter_secure_storage` (DPAPI текущего пользователя, ключ
  `aer-connect.device.v2`); дочерний процесс Host получает их через анонимный
  канал stdin, на диск не пишет.
- Права хоста по умолчанию: экран, мышь/клавиатура, текстовый буфер; файлы —
  только после выбора папки обмена. «Только просмотр» — выключить «мышь и
  клавиатуру».

## Сборка и упаковка (разработчик)

Те же SDK/FreeRDP, что в `WINDOWS.md`, плюс сборка нативного Host
(`native/aer_shadow`, см. `WINDOWS_HOST.md`).

```powershell
cd core
go build -trimpath -ldflags "-H=windowsgui -s -w" -o E:/build/aer-connect-host.exe ./cmd/aer-connect-host
cd ../apps/connect
flutter pub get; flutter analyze; flutter test
$env:VCPKG_ROOT = 'E:\dev\vcpkg'; flutter build windows --release
cd ../..
./tools/windows/package-connect.ps1 -OutputDir E:/temp/aer-connect-anywhere `
  -FreeRdpPrefix $prefix -HostBundle E:/packages/aer-host-native -HostExe E:/build/aer-connect-host.exe `
  [-GatewayAddress home.example.net:443 -GatewayFingerprint <sha256>]
```

Пакет отказывает, если общие DLL viewer и Host различаются. `connect.json`
содержит только адрес и отпечаток (не секреты). Подпись пакета и политики
SmartScreen/PowerShell установщиком не заменяются.

## Ограничения

Полная матрица проверок — `AER_CONNECT_ANYWHERE_REPORT.md`. Настоящий захват
рабочего стола, ввод в пользовательскую сессию, Windows Home, второй
физический ПК и подключение через интернет/CG-NAT требуют отдельной приёмки.
