# UX спецификация

## Центральная метафора
Cozy Beige Tech Home: изометрический интерактивный дом с 5 стартовыми зонами: Кабинет, Серверная, Гостиная, Сетевая, Автоматизация. Комнаты — цифровые категории, не буквальный план квартиры. Пользователь может переименовать/создать/удалить комнаты.

## Основные экраны desktop
1. `Дом`: сцена, навигация, тонкая панель состояния, уведомления.
2. `Классика`: поиск, карточки, категории, инциденты, быстрые команды.
3. `Объект`: статус, capability-aware действия, метрики, вкладки История/Логи/Сведения/Настройки.
4. `Удалёнка`: desktop, toolbar, monitor selection, clipboard/text entry, file transfer, full screen.
5. `Инциденты`: severity, dependency chain, evidence, timeline, remediation preview, acknowledgement.
6. `Редактор`: палитра ассетов, сцена, свойства, undo/redo, save draft/publish.
7. `Добавить`: мастер 1–3 шага, autoconfig, advanced accordion.

## Взаимодействия
- Single click/tap → выделить + короткая карточка; double-click или primary action → подробности. Touch не зависит от double tap.
- Context menu: relocate/edit/link/logs/favorite/archive, только допустимые права.
- Device status не закодирован только цветом: значок, текст, timestamp.
- Scene and classic — одинаковые capabilities, один и тот же Registry/API; UI режим лишь представление.
- Search работает для скрытых объектов и устройств без визуального представления.
- «Неизвестно» ≠ «ошибка», stale данные визуально отличать.

## Мобильный
Первый запуск: выбор «Изометрический дом» или «Обычный интерфейс», оба полнофункциональны в рамках мобильной политики. Можно переключить позже из меню. Изометрия: swipe комнат, zoom, упрощённые подписи, крупные touch targets. Классика: bottom tabs Дом/Устройства/Инциденты/Команды. Удалёнка: список разрешённых запущенных окон; full desktop отсутствует по политике.

## Accessibility/performance
- Keyboard navigation desktop; screen reader labels; контраст технических данных и предупреждений; reduce motion; scale 100–200%; fallback low-detail scene.
- Для логов моноширинный шрифт, фильтры, копирование выделенного текста, timezone, export с redaction.
- Уведомления «одна причина — один инцидент»: зависимые падения группировать, не скрывая исходных событий.
