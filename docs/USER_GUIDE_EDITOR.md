# Как обустроить дом (редактор)

Редактор позволяет менять дом без JSON и настроек: всё делается мышью и клавишами в разделе **Дом**.

## Войти и выйти
1. Откройте раздел **Дом** и нажмите **«Редактировать дом»** (справа вверху).
2. Чтобы вернуться к обычному просмотру — **«Выйти»** или переключатель **Просмотр**. Если есть несохранённые изменения, приложение спросит: сохранить, продолжить редактирование или отменить изменения.

В обычном просмотре мебель случайно не сдвинуть: перетаскивание там двигает только камеру.

## Поставить предмет
- Слева, вкладка **Каталог**: поиск и категории (Мебель, Компьютеры, Серверы, Сеть, Мультимедиа, Автоматизация, Декор).
- Нажмите на карточку и наведите курсор на комнату — предмет появится полупрозрачным. **Зелёные клетки** — можно поставить, **терракотовые** — нельзя (причина внизу). Кликните, чтобы поставить.
- Можно просто **перетащить карточку** в комнату.
- **R** — повернуть, **Shift+клик** — поставить ещё один, **Alt** — точнее (мелкий шаг), **Esc** — передумать.
- Мониторы, ноутбуки, лампы ставятся на стол, если навести курсор на столешницу; коробки — на полки стеллажа; картины и панели вешаются на задние стены; ковры кладутся под мебель.

## Изменить предмет
- Кликните по предмету — справа откроются свойства. Первый клик только выделяет.
- Чтобы передвинуть — **перетащите выделенный предмет**. Пока вы тянете, видно, где он окажется; если место занято, предмет вернётся.
- В свойствах: название, поворот, размер, оформление (светлее, темнее, шалфей, пыльно-голубой), стрелки для точного сдвига, **Копия** и **Удалить**.
- Правая кнопка мыши — меню с теми же действиями.

## Привязать к устройству
1. Выберите предмет (например, системный блок) → **«Привязать устройство»**.
2. Найдите устройство в списке Registry (поиск по названию, адресу, тегам; «Архив» — показать архивные).
3. Выберите и нажмите **«Привязать к …»**.

Предмет покажет название и состояние устройства из Registry. Удаление предмета из дома **не удаляет** устройство из Registry. Перемещать привязанный предмет можно свободно — привязка сохраняется. Для привязки нужна связь с Core.

## Комнаты
- Вкладка **Комнаты** → **«Новая комната»**: название, назначение, размер, пол, стены → **«Разместить»**. Комната появится рядом с домом: кликните в нужном месте или нажмите **Enter**, чтобы оставить предложенное.
- Выделите комнату кликом по полу. Перетащите её, чтобы перенести (мебель едет вместе), или тяните **кружки на краях**, чтобы изменить размер. Ширину и длину можно менять и в свойствах.
- В свойствах комнаты: пол, стены, освещение (дневной, тёплый вечер, приглушённый, прохладный), копия, удаление. При удалении приложение скажет, сколько предметов исчезнет вместе с комнатой.
- Комнаты не могут накладываться друг на друга; комнату нельзя уменьшить так, чтобы мебель оказалась за стеной.

## Отменить, сохранить, черновик
- **Ctrl+Z** — отменить, **Ctrl+Shift+Z** или **Ctrl+Y** — повторить (кнопки ↶ ↷ сверху). История — справа, когда ничего не выбрано.
- **Ctrl+S** или **«Сохранить»** — записать дом в Core.
- Черновик сохраняется на компьютере сам. Если приложение закрылось, при следующем запуске появится **«Найден несохранённый черновик»** — нажмите «Восстановить».
- Если дом за это время изменили в другом окне, приложение не перезапишет чужие изменения и предложит: загрузить актуальную версию, сохранить ваши изменения отдельной копией дома или продолжить редактирование.

## Клавиши
| Клавиша | Действие |
|---|---|
| Esc | отменить текущее действие / снять выделение |
| Delete | удалить выделенное (с подтверждением) |
| Ctrl+D | копия |
| Ctrl+S | сохранить |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | отменить / повторить |
| R | повернуть |
| G | показать/скрыть сетку |
| F | показать выделенное крупно |
| 0 | весь дом |
| + / − , колесо | масштаб |
| стрелки | сдвинуть выделенное на шаг (Shift — мелкий шаг) |

Пока вы печатаете в поле (например, название), эти клавиши не срабатывают.
