# Боты: руководство пользователя

## Где
Левая панель → **«Боты»**. Сверху — поиск (имя, тег, категория), фильтры по состоянию («В сети», «Есть проблемы», «Недоступен», «Неизвестно»), среде и категории, переключатель «Архив».

## Карточка в списке
Имя, среда (Python-процесс, Docker, Telegram, n8n…), категория, версия; состояние из мониторинга; метка среды («процесс запущен», «остановлен», «адаптер недоступен») или «только мониторинг»; последняя ошибка или причина состояния; CPU, RAM, время работы; когда был последний heartbeat; задания за 24 часа (успешно ✓ / с ошибкой ✗).

«Процесс запущен» ещё не значит «бот работает»: работу подтверждает heartbeat. Без данных бот — «Неизвестно», AER HOME не рисует «зелёный» наугад.

## Добавить бота
«Добавить бота» → 4 шага:
1. **Что добавляем**: новый объект (тип и название) или уже существующий объект из «Устройств»; категория, теги.
2. **Где работает**: среда, сервер, зависимости (например, база данных), имя Docker-контейнера.
3. **Мониторинг**: интервал heartbeat и через сколько секунд тишины считать бота недоступным; источник логов; проверка API Telegram (только если на сервере объявлен файл токена); n8n.
4. **Управление и итог**: управляющий адаптер (их объявляет владелец сервера; занятые другим ботом недоступны) или «только мониторинг»; выдать токен heartbeat.

Токен heartbeat показывается **один раз** — скопируйте его в файл рядом с ботом (подробно — `docs/BOTS_CONNECT.md`).

## Страница бота
- **Обзор** — состояние и причина, heartbeat, последний ответ, время работы, версия, CPU/RAM, среда и PID, последняя ошибка и успех, последнее успешное и неудачное задание, сервер и зависимости с их состоянием, история падений и перезапусков.
- **Нагрузка** — графики CPU и памяти процесса или контейнера (данные мониторинга).
- **Активность** — все события бота.
- **Логи** — журнал бота с поиском и фильтром уровня. **Ошибки** — последняя ошибка, активные инциденты (можно подтвердить), записи уровня error.
- **Задания** — история с фильтром по статусу; у неудачных выполнений n8n — «Повторить» (если разрешено).
- **Управление** — кнопки «Запустить», «Остановить», «Перезапустить», «Проверить соединение» и журнал действий. Недоступная кнопка серая, причина — во всплывающей подсказке.
- **Интеграция** — настройки («Изменить»), workflows n8n (только просмотр), «Новый токен heartbeat», «В архив/Восстановить».
- «Мониторинг» в заголовке открывает диагностику объекта.

## Подтверждение действий
Любая команда, меняющая состояние, сначала показывает окно подтверждения: что будет сделано, через какой адаптер, риски и до какого времени действует подтверждение. «Отмена» ничего не выполняет. После «Подтвердить» команда выполняется один раз (повторный клик или сбой сети не запустит её дважды) и записывается в журнал действий. «Проверить соединение» ничего не меняет и выполняется без подтверждения.

## В доме
Поставьте «Бот-персонаж» (каталог «Автоматизация» в режиме строительства) и привяжите его к боту, как любой предмет к объекту из «Устройств». Значок над персонажем показывает состояние. В карточке объекта появляется блок бота: heartbeat, среда, время работы, последняя ошибка, «Карточка бота», «Ошибки» и разрешённые команды (с тем же подтверждением). «Диагностика» ведёт в мониторинг.

## Архив
«В архив» убирает бота из списка и мониторинга, **не останавливая** его. История сохраняется. Вернуть — фильтр «Архив» → бот → «Восстановить».
