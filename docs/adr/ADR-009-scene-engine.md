# ADR-009: Движок изометрической сцены (M03)

**Статус:** ACCEPTED (2026-10-26). Закрывает условие ADR-002: Flame — ACCEPTED после замера. Контракт `openapi.yaml` 0.3.0 → **0.4.0**, новый `contracts/scene.schema.json` v1.

## Решения

1. **Формат v1** (`docs/SCENE_FORMAT.md`): единое понятие `entityBinding` (UUID Registry), UUID для всех id, геометрия ассетов в сцене, только тестовые `visualState.demo`. Противоречия черновика (`deviceBinding`, `room-office`) устранены; пример переписан.
2. **Хранение:** отдельный модуль Core `scene` (таблицы `scene_*`, без доступа к Registry), revision + 20 ревизий истории. Клиент держит атомарный кэш для офлайна. Демо-планировка в Core пишется только по кнопке.
3. **Разделение модулей клиента:** model/codec/edits (чистый Dart) · geometry (проекция, сортировка, hit-test) · camera (математика без Flame) · binding (Registry → представление) · repository/controller · render (Flame) · interaction · UI-оверлеи (Flutter). Привязка к Registry только через `RegistryApi`.
4. **Flame** — игровой цикл, World/CameraComponent (синхронизируется с `SceneCamera`), компоненты; ввод и оверлеи — Flutter (`GestureDetector`, `MouseRegion`): одна логика для мыши и будущего touch.
5. **Временная графика — процедурная** (векторные изометрические объёмы, палитра Cozy Beige), явно помечена `placeholder`; замена на спрайты меняет только реестр отрисовщиков (`docs/SCENE_ART_ASSETS.md`).
6. **Производительность:**
   - статичная часть записывается в один `ui.Picture` на состояние (не на кадр);
   - **растровый кэш:** картинка рендерится в текстуру ≤3072 px; при движении камеры рисуется текстура, после остановки на масштабе выше разрешения текстуры — один чёткий векторный кадр;
   - движок **сам ставится на паузу** без движения; анимируемые значки (критично/загрузка) — ~15 кадров/с; reduce-motion отключает анимации;
   - без анимированных состояний простой ≈ 0,2 % CPU.
7. **Отказ от `BlendMode.softLight`:** на Impeller (Linux, дискретная GPU) давал полосы-артефакты при растеризации; свет ламп — обычное смешивание.

## Альтернативы
- Tiled-карты как формат хранения — отвергнуто: редактор свой (M04), формат должен быть независим от Flutter; Tiled остаётся инструментом авторинга.
- Рисовать кадр вектором всегда — замер: 9–22 мс растеризации на кадр, до 157 пропущенных кадров из 174 при 105 объектах.
- Градиенты вместо blur — замер хуже (растр 12–40 мс), откатили.
- Свой движок/3D — запрещено заданием и избыточно.

## Последствия
- Видеопамять: текстура до ≈24 МБ на сцену; при приближении сильнее разрешения текстуры во время движения изображение мягче (после остановки — чётко).
- Android читает тот же JSON своим рендерером (ADR-016); Flutter остаётся рендерером Windows/Linux. Историческая ветка iOS/ADR-005 отменена владельцем 2026-10-28 и не блокирует сцену; материалы сохраняются.
- Редактор M04 использует `SceneEdits` (чистые операции + валидация) и `PUT /scenes/{id}` с revision.
