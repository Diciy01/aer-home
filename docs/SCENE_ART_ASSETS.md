# Художественные ассеты и каталог сцены

**Статус M04 (2026-10-27):** все 33 предмета, 7 полов и 6 стен — **временная процедурная графика** (`art.kind = procedural`, `art.status = placeholder`). В M04 проведён проход по единому стандарту (ниже): эталонный кабинет (стол, монитор, кресло, лампа, растение, ковёр, картина) перерисован заново, добавлены 7 новых предметов каталога. Это **не финальные ассеты**: инструментов для рисования финальной графики в среде разработки нет, сторонние ассеты неизвестной лицензии не использовались. Финал — по брифу ниже.

История: M03 — 26 процедурных ассетов (`asset_painters.dart`); M04 — стандарт, эталонный кабинет и новые предметы (`home_art.dart`), каталог как данные.

## Каталог (Asset Catalog)
Единственный источник — `apps/desktop/lib/src/scene/catalog/scene_catalog_data.dart` (данные в форме JSON, парсер — `scene_catalog.dart`). Тест `catalog geometry matches every asset of the demo scene` не даёт ему разойтись с документами.

Поля предмета: `id`, `label`, `category` (Мебель, Компьютеры, Серверы, Сеть, Мультимедиа, Автоматизация, Декор), `group` (Столы, Мониторы…), `footprint [w, d]` и `height` в клетках (1 клетка = 0,5 м), `placement` (`floor` / `surface` / `wall` / `overlay`), `bindable`, `top` (на крышку можно ставить), `shelves` (высоты полок), `wallZ` (высота по умолчанию на стене), `keywords` (поиск).

Материалы: `floors` (`id`, `label`, `color`, `pattern`: planks / tiles / stone / carpet / plain, `texture` — зарезервировано), `walls` (`id`, `label`, `color`, `texture`), `lights` (`tint` с альфой = сила), `finishes` (отделки предметов, `tint`). Новый материал = новая запись; кода с условиями по id материалов нет (рисовальщик выбирается полем `pattern`).

## Стандарт оформления (единый для всех ассетов)
- **Проекция** 2:1, клетка 64×32 px на масштабе 1, высота 36 px на клетку; якорь — минимальный угол основания; основание строго в пределах `footprint`, верх — в пределах `height`.
- **Свет** сверху-слева: верх светлее, грань `+y` средняя, грань `+x` темнее (делает `IsoPen.box`); мягкий блик по видимым верхним рёбрам, **без чёрных обводок**.
- **Палитра** Cozy Beige (`ScenePalette`, `docs/DESIGN_TOKENS.md`): дуб `#CFA578`/верх `#DDB88C`, орех `#8E6A4E`, шалфей `#8DA78C`/`#6F8C70`, крем `#F4E9D8`, молочный `#FBF6EE`, графит `#55504C`, акценты — терракота `#C57A64`, янтарь `#D9A55B`, пыльно-голубой `#8FA8B6`. Без неона и кислотных цветов, без надписей и адресов на картинках.
- **Детали** на тон темнее своей поверхности (ручки, швы, кромки); латунь `#C9A46A` — только для мелких акцентов.
- **Тени**: контактную тень и пятна света ламп рисует движок; ассет сам тень не рисует.
- **Состояния**: экраны и светодиоды берут цвет из `ArtContext` (вкл/выкл, `led` по состоянию); никаких «зелёных» состояний для непривязанных устройств.
- **Читаемость силуэта** на масштабе 0,6: крупные массы, не больше 3–4 уровней деталей.

## Как заменить на настоящие изображения (без изменения логики сцены)
1. Нарисовать спрайт по брифу и положить в `apps/desktop/assets/art/<id>/…` (атласы @1x/@2x/@3x).
2. В документе сцены у ассета: `art: {"kind": "sprite", "ref": "<атлас#кадр>", "status": "final"}`; `footprint`/`height` не меняются — геометрия, сортировка, выбор и проверка размещения от картинки не зависят.
3. Добавить загрузчик спрайтов рядом с `proceduralArt` (реестр ref → отрисовщик). Код сцены, камеры, редактора и привязок не меняется.
4. Текстуры полов/стен: заполнить `texture` у материала; рисовальщик пола использует его вместо `pattern`.
5. Лицензия: собственная или CC0/CC-BY с указанием автора в `apps/desktop/assets/art/LICENSES.md`. Ассеты The Sims и других игр не использовать.

## Бриф спрайтов
- Ракурсы: минимум «лицом к `+y`» и «лицом к `+x`» (повороты 0/90), обратные — «спинка» (180/270) для мебели со спинкой; симметричные предметы — один ракурс.
- Кадры состояний: экран выкл/вкл; индикатор нейтральный/шалфей/янтарь/терракота/серый — либо маска для окраски кодом.
- Отделки (`finish`): либо отдельные кадры, либо маска «окрашиваемых» областей (дерево/ткань).
- Масштаб ×3 для приближения и HiDPI, прозрачный фон, без встроенной тени.
